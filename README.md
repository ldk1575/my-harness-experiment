# my-harness-experiment

기준 도구: Claude Code · 다룬 하네스 기능: **미니멀** (모두의연구소 AI 에이전트 2기, 「에이전트 하네스 톺아보기」 11강 과제)

> 지금은 **사전 등록 단계**다. 가설 · 설계 · 사전 판정식만 커밋했고, 결과는 본 실행 뒤에 채운다.

## 가설

사용자 전역 계층(플러그인 · 스킬 · MCP · 훅 · 사용자 설정)을 끄고 실행하면, 작은 코딩 작업 3개에서 테스트 통과율은 떨어지지 않으면서 작업당 총 입력 토큰과 소요 시간이 줄어든다.

## 실험 설계

| 구분 | 내용 |
| :--- | :--- |
| 고정 | Claude Code 2.1.296, `claude-sonnet-5-5`, fixture 3작업, 같은 요청 문장, 같은 권한 플래그, 실행마다 새 복사본 · 새 세션 |
| 조작 | A = 평소 실행 / B = `--setting-sources project --strict-mcp-config --disable-slash-commands` |
| 측정 | 품질(공개 · 숨긴 테스트 통과) + 비용(총 입력 토큰, 소요 시간, 턴, 수정 횟수, 권한 거부) |
| 사전 판정식 | 세 작업 모두 B 통과 횟수 ≥ A, 그리고 2개 이상 작업에서 B의 토큰 · 시간 중앙값이 둘 다 A보다 작으면 지지. 그 외 기각 |

전체 내용은 [experiment-01.md](experiment-01.md)에 있다.

## 폴더 구성

- `experiment-01.md` — 보고서
- `fixture/` — 고정한 작업 입력 원본 3개와 숨긴 테스트(`hidden_tests/`)
- `traces/` — 실행 기록(본 실행 뒤에 채움)
- `scripts/` — 실행기(`run_experiment.py`)
- `probe/` — 불편을 수치로 확인한 탐침 2회
- `PRD.md` — 이 과제를 시작할 때 쓴 요구사항 문서
