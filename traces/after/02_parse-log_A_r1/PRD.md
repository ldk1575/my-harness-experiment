# PRD — parse.py (ERROR 로그 → 마크다운 표)

## [무엇]
`sample.log` 같은 로그 파일에서 ERROR 레벨 줄만 골라 마크다운 표로 출력하는 CLI 스크립트.

## [기능]
- 각 줄 형식: `날짜 시각 레벨 메시지` (공백 구분, 레벨은 세 번째 칸).
- `parse_errors(lines)` → `[("날짜 시각", 메시지), ...]` 튜플 목록 반환.
- `python parse.py [로그파일]` 실행, 인자가 없으면 `sample.log`.
- 출력은 `| 시각 | 메시지 |` 헤더의 마크다운 표.
- 형식에 맞지 않는 줄(빈 줄, 칸 부족, 날짜/시각 모양 아님)은 건너뛴다.

## [저장/데이터 설계]
저장 없음. 입력은 UTF-8 텍스트 파일, 출력은 stdout.

## [내가 넣고 싶은 기능]
- 가정: 메시지에 `|` 가 있으면 표가 깨지므로 `\|` 로 이스케이프한다.
- 가정: 레벨은 대소문자 구분(`ERROR` 정확히 일치). 메시지 본문의 "ERROR" 는 무시한다.

## [규칙]
- 표준 라이브러리만 사용. 파일이 없으면 stderr 에 안내하고 종료 코드 1.
- Windows 콘솔에서도 한글이 깨지지 않도록 stdout 을 UTF-8 로 재설정한다.

## [통과 기준]
1. `parse_errors` 가 sample.log 에서 정확히 3개 튜플을 돌려준다 (09:02:30, 09:03:44, 09:07:02).
2. `python parse.py` 출력에 `| 시각 | 메시지 |` 가 있고 INFO/WARNING 줄은 없다.
3. 메시지에 "ERROR" 만 들어 있는 INFO 줄(`user searched for ERROR codes`)은 표에 나오지 않는다.
4. 깨진 줄(빈 줄 등)이 섞여도 예외 없이 건너뛴다.
5. `python -m unittest test_parse` 통과.
