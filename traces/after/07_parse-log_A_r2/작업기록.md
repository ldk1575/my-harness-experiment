# 작업기록 — parse.py

1. **PRD 먼저**: 조건이 이미 구체적이라 질문 라운드 없이 가정만 `PRD.md` 에 적고 진행했다.
2. **레벨 판정**: 단순히 줄에 "ERROR" 가 들어있는지 보면 `INFO user searched for ERROR codes` 가 잘못 잡힌다.
   그래서 정규식으로 `날짜 시각 레벨 메시지` 를 나눠 세 번째 칸이 정확히 `ERROR` 일 때만 채택했다.
3. **형식 검증**: 날짜·시각 모양(`YYYY-MM-DD HH:MM:SS`)도 정규식에 포함해, 빈 줄·짧은 줄·날짜가 아닌 줄은 조용히 건너뛴다.
   레벨이 소문자(`error`)인 줄은 요구사항에 없어 대문자 `ERROR` 만 인정했다 (가정).
4. **표 깨짐 방지**: 메시지 속 `|` 는 `\|` 로 이스케이프.
5. **Windows 인코딩**: 한글 헤더 때문에 stdout 을 UTF-8 로 reconfigure.
6. 틀렸다가 고친 것은 없음. 도구 쪽 막힘만 있었다: 임시 파일 생성용 셸 명령이 권한 확인에 걸려서 Write 도구로 대신 만들었다.
