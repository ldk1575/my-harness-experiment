# 작업기록 — parse.py

1. 폴더 확인: `sample.log`, `test_parse.py` 가 이미 있었음. 테스트가 `parse_errors` 반환값과 CLI 출력(`| 시각 | 메시지 |`)을 요구함을 확인.
2. 요청이 구체적이라 질문 없이 진행, 가정은 PRD.md 에 명시(`|` 이스케이프, UTF-8).
3. 1차 구현: `split(maxsplit=3)` 로 4칸 분리 후 세 번째 칸이 `ERROR` 인지만 검사 → 테스트 통과.
4. **틀린 지점**: 직접 만든 잘못된 입력으로 확인하니 `bad line ERROR x` 가 `("bad line", "x")` 로 통과됨. 날짜·시각 형식을 검증하지 않았기 때문.
   → 정규식 `^YYYY-MM-DD HH:MM:SS 레벨 메시지$` 로 교체. 재확인 결과 형식 불일치 줄은 모두 제외됨.
5. 환경 메모: Windows 콘솔 기본 인코딩이 cp949 라 한글 헤더 출력 시 깨질 수 있음 → 확인은 `python -X utf8` 로 실행 (테스트는 자체적으로 UTF-8 지정).
